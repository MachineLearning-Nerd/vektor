Publish the final `v0.1.0` skeleton release after the combined Phase 1 review is clean. This is the irreversible part: push release commit, wait for CI success on that commit, make the repo public if required, tag `v0.1.0`, push the tag, and create a notes-only GitHub Release.

- [ ] Final release commit is pushed to `origin/main`
- [ ] `ci.yml` run for the release commit explicitly concludes `success`
- [ ] Repo visibility is `PUBLIC` before the unauthenticated install gate

## Verification

```bash
git status --short
gh run list --commit "$(git rev-parse HEAD)" --workflow=ci.yml --limit 1 --json conclusion -q '.[0].conclusion'
gh repo view MachineLearning-Nerd/vektor --json visibility -q '.visibility'
git ls-remote --tags origin v0.1.0
gh release view v0.1.0 --json assets -q '.assets | length'  # expect 0
```

## Publish Commands

```bash
git push origin main

RELEASE_SHA=$(git rev-parse HEAD)
sleep 20
RUN_ID=$(gh run list --commit="$RELEASE_SHA" --workflow=ci.yml --limit 1 --json databaseId -q '.[0].databaseId')
gh run watch "$RUN_ID" --exit-status --interval 60

if [ "$(gh repo view MachineLearning-Nerd/vektor --json visibility -q '.visibility')" = "PRIVATE" ]; then
  gh repo edit MachineLearning-Nerd/vektor --visibility public --accept-visibility-change-consequences
fi

git tag -a v0.1.0 -m "v0.1.0 — Skeleton release"
git push origin v0.1.0

gh release create v0.1.0 \
  --title "v0.1.0 — Skeleton" \
  --notes-file release-notes-v0.1.0.md
```
